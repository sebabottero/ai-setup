# AGENTS.md

ai-setup: one permission guard, policy and rule set that installs into Claude Code, OpenCode and Codex.
This file is for agents working inside this repo. It is not installed anywhere; the generic rules live in `core/AGENTS.md`.

## Run the tests
```bash
python3 -I -m unittest discover -s tests
```
Try an install without touching real config: `./install.sh --dry-run`.

## Layout
- `core/`: tool-agnostic source (rules, agents, skills, `policy.json`, `guard/`).
- `adapters/`: how each tool is wired (hooks, plugins, settings).
- `docs/`: `REFERENCE.md`, `cheatsheet.html`, assets.
- `tests/`: the suite above.

## Boundaries
- `docs/cheatsheet.html` weighs ~17k tokens: do not read it whole. Use `grep -n` and edit only the piece.
- Protected paths (`protected_paths` in `core/policy.json`) ask for OK; a ticket scope can grant a listed path for a while.
- `build/` is generated by `install.py`: never edit it by hand.
