Tu equipo de agentes, en una carpetaYour agent team, in one folder

Escribes las reglas, los agentes y las skills una sola vez, en capas: core/ (genérico, viene en el repo) y las tuyas, opcionales, que puedes guardar en otro repo y cargar con --layers-dir. El instalador compone las que elijas y las traduce a cada herramienta que abras desde Orca. core/ no contiene nada de ningún repo, empresa ni persona.

You write rules, agents and skills once, in layers: core/ (generic, ships in the repo) and your own optional ones, which you can keep in another repo and load with --layers-dir. The installer composes the ones you pick and translates them for every tool you open from Orca. core/ holds nothing from any repo, company or person.

2. Dentro de Claude el sandbox no deja escribir en ~/.claude ni en build/. Corre el comando tú, con ! delante: ! ./install.sh.2. Inside Claude the sandbox cannot write to ~/.claude or build/. Run the command yourself with a ! prefix: ! ./install.sh.

Regla YodaYoda rule

Añade un agente solo si el trabajo necesita una forma realmente distinta de operar. Si cambiar de agente pesa más que el trabajo, sobran agentes.Add an agent only when the work needs a truly different way of operating. If switching agents costs more than the work, you have too many agents.
